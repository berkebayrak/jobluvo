KanbanCard: company line with logo and match, role title, last event and date. The column it sits in is its status, so it carries no tag.

```jsx
<KanbanCard company="Datadog" logo={url} title="Director, Strategy" match={88} event="Second round booked" date="3 Sep" />
```

Columns sit on surface-1 with a 1px border. Hover turns the card border black.
