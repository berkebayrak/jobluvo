Banner: one line, icon, bold lead sentence, plain follow up, actions on the right. Attention uses a black border. Never a coloured fill.

```jsx
<Banner title="Salesforce needs an answer from you." body="The form asks about US work authorization." primary={<Button variant="primary" size="sm">Answer</Button>} secondary={<Button size="sm">Later</Button>} />
```

Only one banner per screen. If nothing needs the user, show nothing.
